# Attribution for title-map.json

`title-map.json` is generated by `scripts/build-title-map.ts`. The source URLs, versions and sha256 of the downloaded files are recorded in the file itself (`sources`). Read side: `src/lib/jobs/title-map.ts`.

## O*NET

This file includes information from the O*NET 31.0 Database by the U.S. Department of Labor, Employment and Training Administration (USDOL/ETA), used under the CC BY 4.0 license (https://creativecommons.org/licenses/by/4.0/). O*NET® is a trademark of USDOL/ETA. Velai has modified all or some of this information: titles are normalised, occupations are linked by shared detailed work activities and software, and links are combined with other sources. USDOL/ETA has not approved, endorsed, or tested these modifications.

- `db_31_0_text.zip` from https://www.onetcenter.org/dl_files/database/db_31_0_text.zip, fetched 2026-10-31, sha256 `6883548adf5fde64cf6f801b35d15519c9225f2732c3cab0e281c652d16b23a9`. Files read: Occupation Data, Job Titles, Sample of Reported Titles, Related Occupations, Tasks to DWAs, Software Skills.
- `ESCO_to_ONET-SOC.xlsx` (the O*NET Center's ESCO to O*NET-SOC crosswalk) from https://www.onetcenter.org/crosswalks/esco/ESCO_to_ONET-SOC.xlsx, fetched 2026-10-31, sha256 `bf6c854f7ffc935eba67a296d6d7fa4d40b70fb26bcdb5ecb5621374bca6f35b`. Used to place O*NET occupations in ISCO-08 groups once ESCO is loaded.

## ESCO

Not in this build: the ESCO API (ec.europa.eu) could not be reached from the build machine on 2026-10-31. ESCO may be reused for any purpose with an acknowledgment (Commission Decision 2011/833/EU); add its acknowledgment wording here when the build includes it.

## Velai postings

Not in this build. When `scripts/title-map/learn-from-postings.ts` output is passed to the builder, the file adds titles and links learned from Velai's own job index (titles, counts and links only; no posting text or company names).
