# Attribution for title-aliases.json

`title-aliases.json` is generated by `scripts/build-title-aliases.ts` from Wikidata occupation items. The source URL, version and sha256 of the downloaded file are recorded in the file itself (`sources`).

## Wikidata

Wikidata data is released under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/), so no attribution is required; the source is named here for provenance. Licence page checked 2026-10-26: https://www.wikidata.org/wiki/Wikidata:Licensing

- Endpoint: https://query.wikidata.org/sparql (descriptive User-Agent, batches of 400 ids, 2 s apart).
- Fetched: 2026-10-26. Result file `wikidata-occupations.json`: 11,958 items (5,220 with English aliases), sha256 `fa37aaa1818f16a7db9c3b84beb06f75347358462feecad8d9b7c76a24d1b554`.
- Item query (the loader, `scripts/title-alias-sources/wikidata.ts`, builds the label query for each batch of ids):

```sparql
SELECT DISTINCT ?item WHERE { VALUES ?root { wd:Q28640 wd:Q12737077 } ?item wdt:P31|wdt:P279 ?root . }
```

```sparql
SELECT ?item ?label (GROUP_CONCAT(DISTINCT ?alias; separator="|") AS ?aliases) WHERE {
  VALUES ?item { wd:Q... }
  ?item rdfs:label ?label . FILTER(LANG(?label) = "en")
  OPTIONAL { ?item skos:altLabel ?alias . FILTER(LANG(?alias) = "en") }
} GROUP BY ?item ?label
```

Only Q-items are kept (the query also returns a few properties). A name held by more than one item is dropped everywhere, so a shared name never expands.
